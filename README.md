# GitHub Explorer 🔍

Uma aplicação web simples que permite buscar e visualizar repositórios públicos do GitHub de forma prática e organizada. Este projeto foi desenvolvido como parte dos estudos com React e consumo de APIs REST.

## 📸 Demonstração

Acesse o projeto online: [https://marcelobueno25.github.io/explorer.github.io](https://marcelobueno25.github.io/explorer.github.io)

## 🚀 Funcionalidades

- 🔍 Busca de repositórios públicos pelo nome no GitHub
- 📂 Visualização de informações detalhadas do repositório:
  - Nome
  - Descrição
  - Número de estrelas ⭐
  - Número de forks 🍴
  - Dono do repositório (nome e avatar)
- 💾 Histórico de repositórios buscados, salvo localmente

## 🛠 Tecnologias Utilizadas

- [React](https://reactjs.org/)
- [React Router DOM](https://reactrouter.com/)
- [Axios](https://axios-http.com/)
- [Styled Components](https://styled-components.com/)
- [TypeScript](https://www.typescriptlang.org/)
- [GitHub REST API](https://docs.github.com/pt/rest)

## 💻 Como executar o projeto localmente

### Pré-requisitos

- Node.js (versão recomendada: 16 ou superior)
- npm ou yarn

### Passo a passo

```bash
# Clone este repositório
git clone https://github.com/marcelobueno25/explorer.github.io

# Acesse a pasta do projeto
cd explorer.github.io

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm start
